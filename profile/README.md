**What restaurants run on Loyii**

- Points, rewards, stamp cards and membership tiers, with a member card on the phone and in Google Wallet
- A WhatsApp inbox for the team, with replies from the restaurant's own information
- Table Tap: a page on every table for the menu, calling staff, Wi-Fi and feedback
- Bookings, pickup orders and a menu page with photos, halal labels and allergens
- Loyii Recap: catch up on busy WhatsApp chats in seconds
